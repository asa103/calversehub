# Produto

O CalverseHub não é apenas um site de ferramentas.

É uma plataforma de produtividade.

Toda ferramenta deve responder a uma necessidade real do usuário.

Cada ferramenta deverá possuir:

- Interface simples
- Resultado imediato
- Explicação detalhada
- Exemplos
- Compartilhamento
- SEO completo
- Excelente experiência mobile

Nenhuma ferramenta será criada apenas porque é possível desenvolvê-la.

Ela deverá gerar valor para o usuário.
